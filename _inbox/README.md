# _inbox

Sas des fiches créées par un clic sur un lien non résolu dans Obsidian. **Rien ne doit rester ici.** Compléter le frontmatter depuis un gabarit de `_meta/templates/`, puis déplacer dans le bon dossier de `codex/` — Obsidian met les liens à jour tout seul (`alwaysUpdateLinks`).
